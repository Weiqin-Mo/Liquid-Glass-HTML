# Liquid Glass UI Web

一个使用原生 HTML、CSS 和 JavaScript 实现的液态玻璃交互实验。通过 Canvas 位移贴图、SVG 滤镜与 `backdrop-filter` 模拟背景折射，同时提供分段选择器、按钮、开关、滑块和可收起的控制面板。

无需安装前端依赖，无需构建。当前版本已将原来的重复实现拆成共享脚本，并为大面板与小控件分别提供折射引擎。

## 快速开始

```sh
git clone https://github.com/Weiqin-Mo/Liquid-Glass-HTML.git
cd Liquid-Glass-HTML
```

直接在浏览器中打开：

- [完整组件展示](./Liquid-Glass%20index.html)：包含各类控件和参数面板。
- [分段指示器展示](./分段指示器.html)：集中体验胶囊滑动、弹簧吸附与玻璃折射。

保留页面旁边的 JS、CSS 和图片文件；页面不再是可单独拷贝的单文件实现。背景使用根目录的 `bg.jpg`，居中铺满视口；图片缺失时显示渐变背景。

## 交互效果

### 分段选择器

- 点击切换采用可打断的弹簧动画，连续点击时从当前位置转向。
- 按住拖动保持抓取位置，支持轻微上下位移和边缘阻尼，松手吸附最近选项。
- 运动中的玻璃透镜随回弹逐渐恢复白色。
- 支持左右方向键、Home / End，以及原生按钮键盘激活。
- 取消拖动或窗口失去焦点时收敛状态；尊重系统的减少动态效果偏好。

### 滑块、按钮与开关

- 参数滑块使用蓝色填充条和白色圆润胶囊，激活时切换为透明玻璃。
- 胶囊的左右端帽与上下边缘产生对称折射，中间区域保持平稳。
- 开关使用真实的圆钮元素，在切换过程中调用独立的小控件透镜。
- 按钮支持鼠标按压和键盘激活；下拉选择器在获得焦点时启用效果。
- 标题栏及其内部控件不使用小控件引擎，继续走大面板引擎。

### 水滴悬浮面板

- 点击标题栏的 **−**，面板收起为一个 56px 水滴悬浮球。
- 点击悬浮球展开，收展过程包含拉伸、变形和回弹。
- 拖动标题栏可移动面板；悬浮球也可拖动，拖动不会触发展开。
- 收起时保留参数，按 Escape 也可收起。
- 内容过长时面板内部滚动；减少动态效果模式下直接切换状态。

## 参数面板

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| 小控件折射 | 3.00 | 独立控制滑块、分段胶囊、按钮和开关的折射强度，范围 0–6 |
| 背景压暗 | 45% | 只调节背景黑色遮罩；透明玻璃自然采样压暗后的背景 |
| 圆角大小 | 24px | 大面板的圆角 |
| 模糊程度 | 16px | 大面板的背景模糊 |
| 折射强度 | 1.20 | 大面板引擎的边缘位移强度 |
| 液化程度 | 0.60 | 大面板的 swirl / flow 扰动 |
| 亮度 | 1.10 | 大面板玻璃滤镜的亮度 |
| 高光边缘 | 1px | 大面板的内描边宽度 |
| 滑块放大 | 1.30× | 参数滑块的激活放大；分段胶囊为保持稳定限制在 1–1.35× |

大面板参数与小控件折射独立。背景压暗不会直接修改组件的透明度或滤镜参数，但会影响玻璃透出的背景。

## 两套渲染引擎

### 大面板引擎

`liquid-glass-engine.js` 保留圆角矩形 SDF 边缘折射思路：

1. 在 Canvas 中计算位移，并叠加液化扰动。
2. 将位移编码进图像的 R / G 通道。
3. 通过 SVG `feImage` 与 `feDisplacementMap` 接入玻璃元素的 `backdrop-filter`。
4. 按尺寸与参数复用滤镜；缓存超过 96 项时清理未使用项，仍被引用的项不会被删除。

该引擎用于标题栏、卡片和浮动控制面板。页面还通过尺寸观察和视口事件更新贴图。

### 小控件引擎

`small-liquid-glass-engine.js` 单独管理参数、位移图和活跃滤镜，按控件尺寸计算折射，不依赖大面板参数。

激活态参数滑块、分段胶囊和开关圆钮会在 `body` 下创建一个透明透镜层，跟随原控件的屏幕位置与尺寸。这样透镜可以采样下方已绘制的背景、面板、轨道和文字，避免被父级玻璃的背景采样范围隔断。原控件保留布局，交互结束后移除透镜和滤镜并恢复白色。

这里处理的是已绘制画面的合成结果，不会透视不透明面板背后的隐藏内容。按钮等其他小控件在自身表面应用独立引擎。

## 本地验证

前端运行不需要 Node.js。若要运行回归测试，使用 Node.js 22 或更高版本：

```sh
node tests/small-engine.test.cjs
node tests/segmented-control.test.cjs
node tests/panel-controls.test.cjs
```

测试覆盖标题栏分流、透镜位置与尺寸、滤镜回收、折射对称性、强度变化、弹簧中断、拖动取消、键盘操作，以及面板收展和开关/按钮绑定。

这些测试使用模拟 DOM 验证逻辑与位移数据，不代替浏览器截图和视觉验收。当前重构版尚未完成跨浏览器视觉验证；实际折射显示取决于浏览器对 SVG URL 滤镜与 `backdrop-filter` 组合的支持。
